## 🎨 Design & Experience Features

- **Dark Black Mode & Light Mode:** Seamless toggle between crisp daylight mode and an ultra-dark black mode (`#000000` / `#080808`) where all text is rendered in pure white (`#FFFFFF`) and warm gold (`#FBBF24`).
- **Bi-Directional RTL Support:** Built-in Right-to-Left (RTL) mode (`dir="rtl"`) for global accessibility with mirrored navigation and layouts.
- **Straight Single-Row Navbar:** Clean single-line header with icon-only action buttons for Theme Toggle, RTL Direction, Live Case Tracker, and Client Dashboard.
- **Full Responsiveness:** Optimized for 360px mobile viewports, 768px tablets, 1024px laptops, and 4K displays.
- **Smooth Animations:** Integrated AOS reveal transitions, Swiper.js carousel, Lucide icons, and interactive SVG widgets.
